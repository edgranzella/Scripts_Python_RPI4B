# Pruebas de Comunicación - Python (Raspberry Pi) 📡🐍

Este repositorio centraliza una colección de scripts desarrollados en **Python**, ejecutados desde una **Raspberry Pi**, destinados a realizar ensayos, pruebas de estrés y validación de protocolos de comunicación con dispositivos externos (módulos relés, controladores y firmware embebido).

## 📌 Protocolos y Ensayos Incluidos
* Scripts de prueba para comunicación por sockets de red (TCP/UDP).
* Scripts de integración y pruebas de mensajería IoT (MQTT).
* Pruebas de comunicación serial o buses de campo industriales.
